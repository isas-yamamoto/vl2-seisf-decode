# 採否ポリシー（Viking SEISF デコード論文化）

長いセッションログ・試行錯誤をそのまま載せない。**検証可能な結果だけ本文**に載せ、試行経路は必要な限り「失敗の類型」として圧縮する。

## 本文に載せる

| 種類 | 例 |
|------|-----|
| 問題定義 | SEISF(DLT) と VUS(USEIS) の関係、スクランブルの存在 |
| 一次仕様 | PD7400072 の Q ページ読出、N51SUB の NBA/NBB = matv±（Q=matv） |
| 確定アルゴリズム | pair36（36bit から上位4bit 破棄）、Q=matv、bit_offset=15 |
| 検証指標 | vkg.1↔vkg.47 同一ヘッダ照合での 2048/2048 / 450B frame 完全一致 |
| 金フレーム数値 | GCSC=125078、matv=423、year/DOY=1976/249（公開可能な範囲） |
| 一般化できる知見 | レコード境界 spill、フォーマット逆推定の進め方、GT としての VUS の使い方 |
| 限界 | BOUT 命令語完全再現は未完；matv≥503 の稀なパス；カセット媒体誤り |

## 付録に落とす

| 種類 | 例 |
|------|-----|
| 中間の誤った仮説 | Q=matv−2 / off=13 のページ端残差、16-of-18 halfword 詰め |
| 詳細定数表 | MAP BASE 全行（必要なら一部） |
| 擬似コード詳細 | Path A/B/C/E スコアラーの歴史 |
| 追加図 | N51SUB 写真の拡大クロップ |

## 本文に載せない（捨てる／リポの issue 扱い）

| 種類 | 理由 |
|------|------|
| AI エージェント間の逐次チャット | 再現性がない |
| コミットハッシュ列・ツール名羅列 | 科学的主張を支えない |
| 未検証の振幅カタログ全件 | 金フレーム＋代表 N フレームで足りる |
| utig バイナリ全文 | データ権利と容量 |
| materials3 全体の探索コード残骸 | ノイズ |

## 出典ルール

- 数値には一次情報または本リポの `test_regression.py` 実行結果を対応させる
- 未読 PDF を「読んだ体」で要約しない
- 文献の DOI が取れるものは BibTeX に入れる。社内手書きメモは「アーカイブ資料」と明記し著作権に注意
